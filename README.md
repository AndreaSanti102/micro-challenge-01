# micro-challenge-01

INTRODUCTION 
Our micro-challenge involved prototyping a panel for organizing and managing tasks during a day of work in the communal garden. This       initiative stemmed from our previous intervention, in which Max and I attempted to access several communal gardens. The final design is yet to be defined, as we aim to co-create this prototype with the community. However, we have developed a proposal to present at their upcoming monthly assembly.

BRAIN STORMING 
We then conducted a brainstorming session with our professors. Our initial idea was based on addressing some issues we had observed within the community. However, we received insightful feedback suggesting that rather than focusing on solving problems, we should aim to enhance the value of actions and the space itself.

PROTOTYPING 
We initiated the prototyping phase by defining the panel’s dimensions, modularity, and form. Following this, we created a 3D model to facilitate the CNC milling of the wooden components and the laser cutting of the acrylic system for task cards. As a second design layer, we developed a sliding mechanism using custom pieces modeled and produced with a 3D printer.

PANNEL DESCRIPTION 
This panel is designed to visually organize various tasks within a communal garden. Tasks are displayed using an acrylic card system, allowing users to write and erase different assignments as needed. The panels are modular, featuring a simple interlocking mechanism that enables them to be connected in parallel. The goal is to make task management more interactive and organized.
